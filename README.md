# GenAI Token Economics Model

An Excel workbook for judging whether a GenAI use case pays for itself, measured as cost per successful task rather than price per token.

**[Download the workbook](https://github.com/nikhilnan-git/token-economics-template/raw/main/Token_Economics_Template.xlsx)**

## How to use it

1. Open the **Start Here** tab. It is pre-filled with a worked example of four use cases at a fictional firm.
2. Replace the blue cells with your own figures: tasks per month, minutes per task today, hourly cost, how often the AI completes a task without rework, review time, AI cost per task, platform cost and how much saved time becomes a real saving.
3. If you do not know the AI cost per task, leave it blank and select a task size and model class. The sheet will estimate it.
4. Read the results: cost per task today against AI cost per successful task, net value per month and year, return per $1 of AI spend, and the lowest success rate at which each use case still pays.

The remaining tabs hold the detailed model for finance and technical teams: rate cards, platform cost allocation, caching and routing scenarios, sensitivity analysis and a monthly KPI tracker.

## What the worked example shows

In the illustrative example, a 10-point drop in task success reduced monthly net value about 20 times more than a 30% increase in vendor prices, and tokens were only 23% of total AI run cost.

## Disclaimer

The firm, use cases and figures are fictional, and the methodology is a simplified, illustrative framework rather than a validated standard. Adapt its assumptions to your own context before relying on it. Model prices reflect the general range of public list prices and are not quotes from any vendor. This analysis is not based on any organization's data, and the views are the author's own.
